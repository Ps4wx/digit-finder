# NUM_CRACK v2.0 — Missing Digits Finder

> Hacker-themed 10-digit number brute-force tool. Pure HTML + CSS + JS. No dependencies.

## Features

- Matrix rain background animation
- Terminal-style boot screen with progress bar
- Glitch effect title
- Scanline overlay for CRT feel
- Live clock in top bar
- 10-digit number input with position selector
- Generates all 1000 combinations instantly
- Filter/search results
- Fully responsive

## Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/digit-finder.git
cd digit-finder
# VS Code → index.html → Right click → Open with Live Server
```

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "feat: NUM_CRACK v2.0 hacker theme"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/digit-finder.git
git push -u origin main
# Then: Settings → Pages → main branch → Save
```
